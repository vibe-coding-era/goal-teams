# Agent Product Manager Member Workflow

1. 读取 Goal Packet、需求规格卡和 `references/agent-development/INDEX.md` 的目标分片。
2. 为每个用户动作定义目标、所需上下文、工具/权限、可见状态、失败和人工接管。
3. 选择可组合方案及模块；缺少来源或关键产品决策时报告 Lead，而非补造能力。
4. 写 Prompt/Context/Cache、工具与 Evidence 合同，并让前后端/测试能分别实施和验证。
5. 把每项功能验收标准映射到 Harness 与独立测试；提交 revision-bound artifact/review event。
6. 请求不同 member/run 对产品语义、过度声明和安全边界复核。
